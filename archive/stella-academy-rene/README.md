## 世界と学園

- ステラ・アルカナは「静寂の空」に浮かぶ魔法文明の群島であり、星と海が交差する学園都市をコンセプトとする。
- 夜空の「源流の星（ステラ・マリス）」の光が万物の魔力の源。光を直接受け凝縮できる場所は聖域とされる。ステラ・マリスは高次元のエネルギーが世界に漏れ出す「魔力の心臓」と説明される。輝きには周期があり、強い時期は魔導回路が活性化し、弱い時期は魔法の行使が難しくなる。
- ステラ・アカデミーは群島内にある魔法使いの最高峰を育てる学校。世界から「空の上の恒星」と呼ばれ、憧れを集める。
- 入学生は自らの魔力の性質・資質と共鳴する四つの寮のいずれかへ振り分けられる。プロットではユーザーの所属寮・学年・性別を自由に設定できる。

### 四つの寮

| 寮 | 現存する理念・性質と得意分野 |
| --- | --- |
| ルビー（情熱） | 行動力と正義感。物理的な破壊、強力な防御、生命力を操る光の魔法 |
| ダイアモンド（静謐） | 沈着で思慮深い。催眠・幻術、重力操作、短時間の時間遡行など精神・概念に関わる魔法 |
| サファイア（英知） | 知識欲、分析力、創造力。占星術、転移などの空間操作、結界魔法 |
| オパール（変幻） | 自由奔放、個性、直感とひらめき。属性変換、錬金術、精霊や獣の召喚 |

### 魔力と道具

魔法使いは体内に取り込んだステラ・マリスの光を魔力に変える。生の光は人体に危険であり、カリスを通さず浴び続けると肉体の結晶化や精神の消失・自我の崩壊に至る「星化現象（ステラリゼーション）」が起こる。学園から授与される寮の宝石「ステラ・コア」は、猛烈な光を人が扱える状態へ変換するフィルター兼変圧器の役割を持つ。コアを組み込んだ「星導具（カリス）」は魔力を制御・増幅する各人向けの道具で、杖や魔導書などの形を取る。公開資料には「魔導具」「星導具」の両表記があるため、統一して改称しない。
